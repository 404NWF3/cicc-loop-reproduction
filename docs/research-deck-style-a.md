## 实现与许可

模板来源与 AGPL-3.0 原文随演示提供。模板、布局、研究数据、样式与构建脚本共同生成一个可独立运行的 HTML，由现有网站路由内嵌。演讲者模式沿用模板的观众屏同步、备注、计时、排练和恢复功能。应用侧桥接支持深链接、浏览器返回、资料面板与现场实验跳转。

页面按模板的 P0 检查项核对字体、图片边界、标题换行、明暗节奏、页码、讲稿和演讲者模式；网页集成测试验证实际交互与本地资源加载。

## 构建与修改

`npm run dev` 和 `npm run build` 自动运行 `web/presentation/build.mjs`。原始研究文本与配对图数值仍位于 `web/src/presentation/slides.json`、`local-results.json`；`web/presentation/plan.json` 管理版式、稳定 ID 对应关系、每页目的和转场。`content.mjs` 按 Style A 布局输出内容，`style-a.css` 适配网站尺寸，`bridge.js` 连接路由与模板运行时。修改这些文件后，重新运行构建脚本或重启开发服务器即可预览。

生成的 `web/public/presentation/deck.html` 和 `source/` 不入 Git，生产构建自动生成。后者提供当前部署版本的对应源码，许可原文独立保留。不会增加服务端进程或运行时依赖。字体按新增标题与正文补齐 Noto Serif CJK SC 字符子集，当前文件 315,752 字节，许可保持 SIL OFL。
